# Автомобильный рынок Казахстана

Очистка данных о продажах автомобилей за январь–сентябрь 2019 года и анализ позиций «Меркур Авто».

## Состав проекта

| Файл | Содержание |
| --- | --- |
| [report_mercura_eda.docx](report_mercura_eda.docx) | Отчёт с выводами, методологией и источниками |
| [autokz2019_analysis_base.csv](autokz2019_analysis_base.csv) | Аналитическая база: 39 966 строк, 17 полей; совпадающие наблюдения сохранены |
| [clean_autokz.py](clean_autokz.py) | Скрипт очистки с двумя режимами дедупликации |
| [autokz2019.csv](autokz2019.csv) | Исходные данные |

## Запуск

Требуются Python 3.10+ и pandas 2.2+.

```bash
pip install "pandas>=2.2"
python clean_autokz.py autokz2019.csv autokz2019_analysis_base.csv
```

Основной анализ сохраняет совпадения: без VIN или ID сделки одинаковые атрибуты не доказывают повторную загрузку продажи. Для получения единственного итогового CSV по ТЗ с удалёнными точными дублями:

```bash
python clean_autokz.py autokz2019.csv autokz2019_clean.csv --drop-exact-duplicates
```

Этот файл создаётся локально и в состав репозитория не входит. Различия между режимами и границы интерпретации показателей описаны в отчёте.
